# 效果图反向分层与高保真还原

## 输入分级

- **A级：平面目标图**。无透视、无环境、光照均匀。可直接拆层。
- **B级：透视包装图**。先校正目标面透视，并让用户批准平面化结果。
- **C级：三维环境效果图**。先移除环境、阴影、反射和材质光效，重建均匀平面目标图。不得把受光颜色当作印刷颜色。
- **D级：低清、重遮挡或多面不可见**。只能部分提取，必须列出推测性补全并降低可信度。

## 元素清单

在处理像素前列出每个可识别元素。每项至少记录：

- `id`：稳定且唯一，例如 `main-flower-001`。
- `name`：人类可读名称。
- `group`：五个固定组之一。
- `source_method`：`source-extracted`、`occlusion-completed`、`upscaled-rebuilt`、`retyped` 或 `manual-redraw`。
- `confidence`：`high`、`medium` 或 `low`。
- `occlusion`：`none`、`partial` 或 `full`。
- `file`：相对清单路径。
- `isolation_mode`：`opaque-layer`、`transparent-png` 或 `layer-mask`。
- `mask_file`：使用 `layer-mask` 时对应的全画布黑白蒙版路径；白色显示、黑色隐藏、灰色保留半透明边缘。
- `deferred_split`：是否允许在效果图确认后再精拆。
- `contains`：当前合并视觉单元中包含的可识别子元素名称，防止后续漏拆。
- `notes`：错字、颜色不确定、边缘风险或待确认事项。

不要忽略小印章、细边框、角标、辅助线、散点、局部底纹和数字。快速预分层时可以先把同组且容易后拆的项目合并，但必须把子元素写入 `contains`，不能因为少分层而从清单中消失。

## 提取优先顺序

1. 锁定画布、坐标和批准的目标图。
2. 直接复制完整可见区域，使用蒙版保留抗锯齿边缘。
3. 从顶层元素向底层元素依次移除覆盖物。
4. 对背景先使用明确底色、重复纹理或邻近像素恢复；只有无法恢复时才使用生成补全。
5. 对部分遮挡图案，保留可见像素并只生成缺失部分；用缺失区域蒙版限制生成结果。
6. 对完全遮挡元素，不声称已恢复原始内容。按上下文重建并标记 `low`，等待用户确认。
7. 对文字优先保留批准图中的像素外观；模糊字、乱码和错字单独列出，不擅自更换。

## 生成和编辑约束

每次只处理一个元素或一个连续视觉单元。提示词重复以下不变量：

- 保持画布、构图、比例、色彩、线宽、边缘和已提取像素不变。
- 只补全透明或被遮挡区域。
- 不新增文字、图案、边框、阴影、光效、纹理或装饰。
- 输出完整元素，不裁切边缘。
- 非背景元素优先使用透明背景；若透明提取会伤害边缘，则保留完整像素层并单独制作黑白蒙版，不强求透明 PNG。

处理复杂边缘时，可先生成纯色键背景，再进行软蒙版、去溢色和边缘收缩；若仍不稳定，直接交付“完整像素层 + 蒙版”。不要用整图重新生成替代精确提取。

## 高清处理

根据最终物理尺寸计算目标像素。没有物理尺寸时，保留当前像素尺寸并标记概念稿，不凭空声称达到印刷要求。

- 原图达到目标像素：保持原像素，只清理边缘和压缩噪点。
- 原图接近目标像素：使用保边放大，避免锐化光晕和过度纹理。
- 原图明显不足：局部重建图案；文字、线条和规则几何优先矢量化。
- 新增细节必须标记为重建内容，不能描述为原始细节恢复。

## 重组检查

1. 按五组和元素顺序重新叠加。
2. 与批准目标图严格对齐。
3. 输出普通重组预览和放大的差异图。
4. 检查每个清单元素是否存在、坐标是否一致、透明边缘或蒙版边缘是否有白边、色边或孔洞。
5. 对直接提取区域检查颜色和像素是否被改动。
6. 对补全区域人工检查风格连续性和印刷可实现性。
7. 任何核心主图、产品名或标签为低可信时停止，先让用户确认。

## 交付边界

概念 PSD 可以调整层级、位置、透明度和重要元素，但不等于生产文件。完全被遮挡的像素无法精确恢复；低清放大不能创造可信的原始细节；三维光照色不能直接作为印刷色。把所有这些限制写入还原报告。
